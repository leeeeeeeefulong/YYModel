# 验证前列出的失败场景

本目录独立验证公开 API，不修改库实现，不依赖任何业务 App。

1. 数值字符串（包括超长有效系数与抵消指数、长指数前导零）：正负号、小数、指数前导零、极大/极小指数、零系数；截断方向不一致、溢出被舍入回范围内、有效输入被拒绝。
2. 十六进制浮点（包括二进制移位、小数截断及超长系数与抵消指数）：2^53 邻域、Int64/UInt64 边界；通过 Double 后丢失精度或吸收越界数。
3. 语法完整性：非法尾缀、空系数、重复指数/符号、非 ASCII 数字或带组合标记的数字；Character 区间比较不能保证 ASCII 数字语法。
4. Foundation 高精度数值：NSDecimalNumber 与 JSON 原始数字输入，不能提前降级 Double。
5. 复杂天气载荷：三城市、多层对象、小时/日数组、单位字典、负数、小数、null、空数组、缺失字段、可容错类型；嵌套对象/容器不能丢字段或改变数量。
6. OC 契约：keyPath 映射及 JSON 导出、容器泛型、原版对照；Swift Codable 按自身契约验收，不要求未实现的 OC Mapper 能力。
7. 性能：先验值正确再计时；输入字节固定；网络不纳入计时；预热后多轮采样；错误解码不能以更快为通过依据；每次消费结果并及时释放对象。
8. 可重复性：默认离线使用公开数据快照，记录提供方/URL/许可/获取时间/SHA-256；运行记录源码身份、编译参数、数据规模、完整样本，不能以某个正式业务 App 的状态作为组件标准。

判定基准：数值期望由 Python 的任意精度整数计算；天气投影期望由固定 JSON 直接计算。数据、期望和失败输入都随运行结果保存。
