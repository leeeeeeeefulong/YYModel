# 发布核验：先验失效模式（2026-10-05）

目标：业务可用性和功能准确性。已有475项结果只覆盖原用例；不能推导未验证平台、配置或组合正常。
本轮不发布、不修改版本号；仅对已复现且根因明确的问题做最小修复。生产修改前必须先保存公开E2E失败观察。

1. 独立消费端：源码同编译能通过，但真实SwiftPM产品导入、Swift-only隔离或Swift/ObjC混用可能失败。
2. 运行平台：macOS通过不证明iOS Foundation行为相同；在可用iOS模拟器运行核心模型、数值、规则与ObjC契约。现代SDK下限编译不能替代iOS11–15运行。
3. 编码组合：手写Codable容器、继承、规则/export hook、key/date/data策略、nil/空对象、非有限值或错误回调可能绕过策略、丢值或吞错。
4. 解码组合：raw/Data、默认/回退/required、Presence、lossy、多态、可选与数值日期边界可能产生成功但错误的业务对象。
5. 交付配置：SPM/Podspec/框架源文件遗漏、API可用性或工具链声明与实际编译不符，可能导致消费端无法使用。未实际跑过的交付渠道单列未验证。
6. 修复回归：新复现入库后保留固定期望；修复后重新跑相关消费者与原公开套件。不得通过修改期望掩盖失败。
7. 性能：已有微基准未达长期≤3x目标仅记录，不作为发布阻塞；若实际出现无法完成解析、崩溃或资源耗尽则按业务故障处理。

每条确认问题记录现象、输入/条件、影响、严重度、根因/方案、状态及证据。没有复现的疑点标为待证。
